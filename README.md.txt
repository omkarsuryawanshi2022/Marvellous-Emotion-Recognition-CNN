# 😊 Marvellous Emotion Recognition Using CNN

A Facial Emotion Recognition project built using Python, TensorFlow/Keras, Convolutional Neural Networks (CNN), OpenCV, the FER2013 dataset, and Streamlit.

This project detects faces in images and predicts facial expression categories using a trained deep learning model. It provides both an OpenCV webcam application and a Streamlit web interface.

## 🚀 Project Features

- Facial emotion classification using CNN.
- Training using the FER2013 dataset.
- Seven emotion categories.
- OpenCV Haar Cascade face detection.
- Real-time webcam emotion detection using OpenCV.
- Streamlit interface for image uploads.
- Camera photo capture through the browser.
- Emotion labels and model confidence scores.
- Model evaluation and training visualization, if generated by the training script.
- Reusable trained Keras model.

## 🎭 Emotion Categories

The model classifies facial expressions into seven categories:

| Class Index | Emotion |
|---|---|
| 0 | Angry |
| 1 | Disgust |
| 2 | Fear |
| 3 | Happy |
| 4 | Sad |
| 5 | Surprise |
| 6 | Neutral |

**Note:** The label order must match the order used when training the model.

### Step 1: Open the project directory


Update the directory if your project is stored elsewhere.

### Step 2: Activate the virtual environment

```cmd

```

If the environment does not exist, create it:

```cmd
py -m venv MarvellousEmotion_env
MarvellousEmotion_env\Scripts\activate
python -m pip install --upgrade pip
```

### Step 3: Install dependencies

```cmd
python -m pip install -r requirements.txt
```

Verify the installation:

```cmd
python -c "import cv2, numpy, streamlit, tensorflow as tf; print('OpenCV:', cv2.__version__); print('NumPy:', numpy.__version__); print('Streamlit:', streamlit.__version__); print('TensorFlow:', tf.__version__); print('CascadeClassifier:', hasattr(cv2, 'CascadeClassifier'))"
```

### Step 4: Prepare the dataset

Place the `fer2013.csv` file in the project directory.

The training script expects the standard FER2013 CSV structure, including the `emotion` and `pixels` columns.

Keep the dataset locally unless you have verified that redistribution is permitted.

## 🧠 Train the CNN Model

Run:

```cmd
python Marvellous_Real_Time_Emotion_Detection.py --mode train --dataset .
```

To see the options supported by your training script:

```cmd
python Marvellous_Real_Time_Emotion_Detection.py --help
```

The training workflow typically includes:

1. Loading the FER2013 CSV dataset.
2. Converting pixel strings into grayscale images.
3. Resizing or reshaping images to 48 × 48 pixels.
4. Normalizing pixel values.
5. Preparing training, validation, and test sets.
6. Building and training a CNN.
7. Evaluating the model.
8. Saving the trained model and any supported evaluation outputs.

The exact training duration and results depend on the computer, model configuration, dataset, and number of epochs.

## 📷 Run Real-Time Webcam Detection

After training and saving the model, execute:

```cmd
python Marvellous_Real_Time_Emotion_Detection.py --mode webcam
```

The application uses OpenCV to detect faces and the trained CNN to predict facial expressions.

Press **Q** or **Esc** to exit if supported by the script.

## 🌐 Run the Streamlit Application

Make sure the following files are available:

- `Marvellous_Emotion_Recognition_Streamlit.py`
- `Emotion_Detection_CNN.keras`
- `emotion_labels.txt` (optional if the application uses default labels)

Start the application:

```cmd
python -m streamlit run Marvellous_Emotion_Recognition_Streamlit.py
```

### How to use the Streamlit app

1. Open the Streamlit page in your browser.
2. Select **Upload image** or **Take a camera photo**.
3. Upload a face image or capture a photo.
4. Click **Detect emotion**.
5. View the detected face and predicted emotion.
6. Review the model confidence score in the results table.

The supplied Streamlit version processes one still image or camera photo per prediction. It does not continuously stream live video.

## 🧯 Troubleshooting

### Model file not found

Check that the model exists:

```cmd
dir Emotion_Detection_CNN.keras
```

Train the model if the file has not yet been generated.

### OpenCV CascadeClassifier error

If you see:

```text
AttributeError: module 'cv2' has no attribute 'CascadeClassifier'
```

Remove conflicting OpenCV packages:

```cmd
python -m pip uninstall -y opencv-python opencv-contrib-python opencv-python-headless opencv-contrib-python-headless
```

Install a compatible OpenCV package:

```cmd
python -m pip install opencv-contrib-python==4.12.0.88
```

Verify:

```cmd
python -c "import cv2; print(cv2.__version__); print(hasattr(cv2, 'CascadeClassifier'))"
```

### Streamlit command not found

Run Streamlit through Python:

```cmd
python -m streamlit run Marvellous_Emotion_Recognition_Streamlit.py
```

### No face detected

Try an image with:

- A clearly visible face.
- Good lighting.
- A front-facing pose.
- Minimal obstruction of the face.

### Webcam not opening

Check Windows camera permissions and close other applications using the camera. You can also use the Streamlit image-upload option.

### TensorFlow dependency errors

Install dependencies inside the activated virtual environment. If package versions conflict, use a Python version supported by your installed TensorFlow version and recreate the environment if necessary.

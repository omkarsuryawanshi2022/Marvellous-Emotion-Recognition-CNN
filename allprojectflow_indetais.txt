PROJECT NAME
------------
Marvellous Emotion Recognition Using CNN, OpenCV, FER2013 and Streamlit

PROJECT OBJECTIVE
-----------------
The objective is to train a Convolutional Neural Network (CNN) to classify facial expressions into seven categories using the FER2013 dataset.

The project includes:
1. Dataset preparation.
2. CNN model training.
3. Model evaluation.
4. OpenCV webcam detection.
5. Streamlit image-based prediction.
6. Git and GitHub project management.

TECHNOLOGIES
------------
Python
TensorFlow
Keras
CNN
OpenCV
NumPy
Pandas
Scikit-learn
Matplotlib
Streamlit
Pillow

EMOTION CLASSES
---------------
0 - Angry
1 - Disgust
2 - Fear
3 - Happy
4 - Sad
5 - Surprise
6 - Neutral

Important: The class order must match the output order of the trained model.

========================================
STEP 7: PREPARE FER2013 DATASET
========================================

Place fer2013.csv in the project directory.

The training script expects a standard FER2013 CSV with at least:

emotion
pixels

The CSV commonly also includes a Usage column.

The dataset contains facial image pixel data and emotion labels.

Keep the dataset locally. Do not push it to GitHub unless redistribution is permitted and intended.

========================================
STEP 8: TRAIN THE CNN MODEL
========================================

Run:

python Marvellous_Real_Time_Emotion_Detection.py --mode train --dataset .

Typical training stages:

1. Read the FER2013 CSV.
2. Parse the emotion label for each row.
3. Convert pixel strings to numerical arrays.
4. Reshape images to 48 x 48 grayscale.
5. Normalize pixel values.
6. Prepare training, validation and test data.
7. Build the CNN model.
8. Train the model for the configured number of epochs.
9. Validate performance.
10. Evaluate the trained model.
11. Save the model and supported outputs.

Training time depends on hardware, dataset size, model configuration and epoch count.

========================================
STEP 9: VERIFY TRAINED MODEL
========================================

Run:

Also check:

Expected model filename:

Emotion_Detection_CNN.keras

If the file is missing, inspect the training output for errors before running inference.

========================================
STEP 10: RUN OPENCV WEBCAM MODE
========================================

Run:

python Marvellous_Real_Time_Emotion_Detection.py --mode webcam

Typical workflow:

1. Load the trained CNN model.
2. Open the webcam.
3. Read a video frame.
4. Convert the frame for face detection.
5. Detect faces with OpenCV Haar Cascade.
6. Extract each face.
7. Resize the face to 48 x 48 pixels.
8. Normalize the pixel values.
9. Pass the face into the CNN.
10. Display the predicted emotion and score.

Press Q or Esc to exit if implemented by the script.

========================================
STEP 11: PREPARE STREAMLIT FILES
========================================

Marvellous_Emotion_Recognition_Streamlit.py

The model file is required for prediction.

If emotion_labels.txt is not present, the supplied Streamlit script uses default labels. Verify that the default label order matches the training script.

========================================
STEP 12: START STREAMLIT
========================================

Run:

python -m streamlit run Marvellous_Emotion_Recognition_Streamlit.py

Streamlit opens the application in a browser.

========================================
STEP 13: USE STREAMLIT APPLICATION
========================================

1. Select Upload image or Take a camera photo.
2. Upload an image or take a photo.
3. Click Detect emotion.
4. The application loads the image.
5. OpenCV detects face regions.
6. Each detected face is converted to grayscale.
7. The face is resized to 48 x 48 pixels.
8. Pixel values are normalized.
9. The CNN predicts an emotion category.
10. The application draws a face rectangle and prediction label.
11. The results table displays the predicted emotion and model score.

The supplied Streamlit version predicts from still images or camera photos. It does not perform continuous live-video inference.

========================================
STEP 14: UNDERSTAND PREDICTION OUTPUT
========================================

Face rectangle:
The location of a face detected by OpenCV.

Predicted emotion:
The class with the highest model output score.

Model confidence:
The highest output score displayed as a percentage.

Important:
The score is not necessarily a calibrated probability and does not prove a person's actual emotional state.

STEP 15: TROUBLESHOOT MODEL FILE ERROR

========================================
STEP 16: TROUBLESHOOT OPENCV ERROR
========================================

If you see:

AttributeError: module 'cv2' has no attribute 'CascadeClassifier'

Uninstall conflicting OpenCV packages:

python -m pip uninstall -y opencv-python opencv-contrib-python opencv-python-headless opencv-contrib-python-headless

Install a compatible package:

python -m pip install opencv-contrib-python==4.12.0.88

Verify:

python -c "import cv2; print(cv2.__version__); print(hasattr(cv2, 'CascadeClassifier'))"

========================================
STEP 17: TROUBLESHOOT STREAMLIT
========================================

If the streamlit command is not recognized, run:

python -m streamlit run Marvellous_Emotion_Recognition_Streamlit.py

If the browser camera is unavailable:

1. Allow camera access in the browser.
2. Check Windows camera privacy settings.
3. Close other applications using the camera.
4. Try Upload image mode.

========================================
STEP 18: TROUBLESHOOT NO FACE DETECTED
========================================

Try:

1. A clear, front-facing face image.
2. Better lighting.
3. A larger face in the image.
4. Less obstruction from masks, hands or objects.

Haar Cascade may fail to detect faces at unusual angles or in low-quality images.
